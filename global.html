cvFind(find, optopt) → {Object}

Description:

  • 檢核並正規化find

    第一步由wsemi之cvOrmFind依系列條件白名單檢核並取得全新之null原型複本(undefined與{}為未給條件，即全部； 傳了值卻不是條件物件者一律reject，不得視同{}而全刪)，之後只走訪該複本做pg專屬限制與轉譯。

    驗證過程中任何例外(含呼叫端物件之getter、Proxy trap、Symbol.toStringTag拋錯)一律轉為invalid find. 可重入(呼叫端之trap再呼叫本函數亦不致影響外層).

cvTable(table) → {String}

Description:

  • 檢核並引用createTable之表名

    兩種形式擇一: ①未含雙引號者, 以.分隔之每一段須為識別字形(reBareSeg, 至多63 bytes), 即一般名稱或schema.table (含空白、連字號、分號、關鍵字等者一律拒絕, 如'IF NOT EXISTS t'不再被當成DDL片段); ②含雙引號者須為完整雙引號名稱(內含之雙引號成對加倍, 以.相接). 兩者經quoteTable(與insert、save等路徑同法)引用後, 須全由雙引號識別字以.相接而成; 否則(含未成對之雙引號、被mongo-sql原樣輸出之JSON取值運算子或::轉型尾巴、空片段、.*)一律拒絕. 不接受非字串、空字串、含NUL或孤立代理字元者.

genConflict(pk, rowopt) → {String}

Description:

  • 產生ON CONFLICT子句(主鍵衝突時更新或跳過)

    更新欄為該筆數據將被INSERT(同colsOf)且非主鍵之欄: ON CONFLICT ("pk") DO UPDATE SET "k" = EXCLUDED."k", ...; 值為undefined之鍵不在INSERT欄單內, 不更動既有欄亦不被引用; 無更新欄(或未給數據)時為DO NOTHING. 主鍵名與欄名皆以quoteKey引用.
